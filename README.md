# VHU VampireHunters Alliance Playbook

Static, phone-first reference for the VHU VampireHunters alliance in Last Z: Survival Shooter, State 788.

https://thebardchat.github.io/vhu-playbook/


## Preview

Download and open `index.html` in a browser. The page has no build step. Checklist progress stays in that browser; the alliance mail button copies text and does not send anything. Use the print button to print only the Attack Day checklist. The production GitHub Pages site is published from the root of `main`; a review branch does not change it.

## Private suggestions

The page shows no submission link until the playbook owner supplies an approved Google Forms **responder** URL. Never use a form edit or response-summary link. Keep access to submissions restricted to the owner, turn off public response summaries, and do not publish responses without the owner's approval. To check access before enabling the link, open it as a non-owner, submit a harmless test, and confirm that only the owner can view it. Enter the approved responder link in `FORM_LINK` in `index.html`. The older embed and discussion variables are not used for suggestions.

A simple form can ask which screen or rule the suggestion is about, what happened, and what should change. Don't collect player IDs, real names, account details, or screenshots by default.

## Game information

Verify event timing, eligibility and scoring in the current in-game event screen. Keep alliance rules separate from in-game mechanics. Don't post member names, account details, power totals, private locations, or in-game screenshots that identify players.
