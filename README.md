# VHU VampireHunters — Alliance Playbook

Simple one-page site for the <VHU> VampireHunters alliance (Last Z: Survival Shooter, State 788).

## Update the site
Edit `index.html`, commit, and GitHub Pages republishes in about a minute.

## Turn on notes and comments
Open `index.html` and fill in the three lines near the bottom:
- `FORM_LINK` — Google Form share link (works for everyone, no account)
- `FORM_EMBED` — Google Form embed link (optional, shows the form on the page)
- `DISCUSSIONS` — this repo's Discussions link (needs a free GitHub account)

## Keep it safe
This site is public. Do not post member power, HQ levels, or personal info here.
